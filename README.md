# JASS Philosophy Classics Explorer v3

A polished local-first PySide6 reader for `JASS_Philosophy_Classics.db`.

## v3 features

- SQLite FTS5 full-text search
- Search result count
- Search-term highlighting in passages
- Clean three-pane research layout
- Passage information panel
- Copy passage
- Reading font controls
- Previous / Next navigation
- Persistent bookmarks
- Dedicated Bookmarks view
- Dark / light theme
- Offline operation
- No heavy AI/PyTorch dependencies
- No invented author/work attribution

## Run

```bash
pip install -r requirements.txt
python philosophy_explorer.py
```

Keep `JASS_Philosophy_Classics.db` in the same folder as the Python application.
